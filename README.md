# Digital-Communications
Some projecets related to (Digital) communication systems

## Communication Systems

This folder includes the implementations of communication systems course:

Implementing the Amplitude, Phase, and Frequency Modulations (AM, DSB, SSB, VSB, PM/NBPM, FM/NBFM), and filter estimation

## Digital Communications Lab

This folder contains the Digital Communications Lab manual and the implementations:

Implementing complete digital communication systems using different modulations (PAM, PSK, QAM, coherent and non-coherent FSK) and plotting the BER curves for real scenarios including noise, delay and phase offset (Hardware implementation using ADLAM-PLUTO)

The folder also contains some other files for the prelabs.

## Advancded Communications

This folder contains the computer assignemnts designed for the Advanced Communications course:

- HW1: An overview of stochastic processes, low-pass and band signals
- HW2: Coherent and non-coherent recievers for digital modulations
- HW3: Implementing different equalizers (ZF, MMSE, DFE, MLSE using viterbi algorithm)
